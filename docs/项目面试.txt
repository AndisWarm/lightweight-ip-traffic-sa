lightweight-ip-traffic-sa   项目负责人
内容:
一个面向 IP 多特征融合的轻量化态势感知系统。项目当前使用“登录鉴权 -> 安全任务 -> 特征采集与评分 -> 总览展示 -> 预警与
记录 -> 安全配置”主链路，并在此基础上接入了基于 gopacket 的流量增强链路，支持离线 pcap/pcapng 深度解析、短时在线
抓包、流量落库、任务级证据回溯与趋势展示。
业绩:
参与并推进 lightweight-ip-traffic-sa 安全流量分析项目，熟练运用 Claude Code、Codex 等智能体辅助完成需求分析、需求文
档编写、技术选型、系统设计、编码实现、测试与部署，覆盖项目完整研发流程。
主导核心业务链路建设，打通“登录鉴权 -> 安全任务 -> 特征采集与评分 -> 总览展示 -> 预警与记录 -> 安全配置”的完整功能闭
环，提升系统在安全检测、任务管理和风险展示方面的可用性。
基于 Go + Gin + Gorm 构建后端服务，结合 MySQL、Redis、JWT、YAML 配置等技术实现用户鉴权、任务管理、数据持久化、缓
存加速和配置化管理。
接入基于 gopacket 的流量增强分析链路，支持离线 pcap/pcapng 文件深度解析、短时在线抓包、流量数据落库、任务级证据
回溯与趋势展示，增强系统对网络流量安全分析的支撑能力。
使用 Vue 3、Vite、Vue Router、Pinia、Axios、Element Plus、ECharts / vue-echarts 构建前端管理界面，实现安全任务、流
量特征、评分结果、预警记录和趋势图表的可视化展示。
完成 Go 1.25.x、Node.js 22.x、MySQL 8.0+、Redis 6.x/7.x 等运行环境下的开发、联调与部署验证，保障前后端功能链路稳定
运行。
