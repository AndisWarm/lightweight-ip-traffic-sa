# 项目深度学习笔记（面试向）

> 面向人群：**编程小白 / 准备面试本项目的人**。
> 目标：读完这套文档，能把项目的每一条链路、每一个技术选型、每一个数据表、每一个评分公式都在白板上讲清楚，并且能回答面试官的连环追问。

## 这套笔记和已有 docs 的关系

仓库里 `docs/` 目录已经有：`架构说明.md`、`功能说明.md`、`系统设计.md`、`评分算法整体框架.md`、`面试记录.md`、`项目成果.md`。它们是「交付/答辩」风格：简洁、结论先行。

本 `docs/learning/` 目录是「**小白学习**」风格：
- 概念先解释再使用，不预设你懂。
- 每个技术点都讲「**是什么 → 为什么用它 → 在项目里在哪 → 面试怎么答 → 可能被追问什么**」。
- 代码引用都给出文件路径，方便你自己跳过去看。

```
│   ├── model/                  # 实体 / 请求 / 响应模型
│   ├── utils/                  # JWT、缓存、分页、角色工具
│   ├── data/                   # GeoLite2 mmdb、本地黑名单
│   └── demo_schema.sql         # 建库建表脚本
└── web/                        # Vue3 前端
    ├── src/api/                # Axios 封装 + 各业务 API
    ├── src/router/             # 路由 + 守卫
    ├── src/pinia/              # 登录态、用户态
    ├── src/view/               # 页面（security、system 两域）
    └── src/components/         # 可复用组件
```

## 怎么用这套笔记

1. **第一遍**：按 00 → 10 顺序读，不求记，建立整体图景。
2. **第二遍**：挑你最不熟的章节，打开对应的源代码文件对着看。
3. **面试前 1 天**：只刷 `10-面试高频问答.md` + `05-评分算法.md` 的手算示例。
4. **面试现场**：如果忘了细节，回到 `00-项目是什么.md` 的 30 秒自我介绍，先稳住节奏再说。
